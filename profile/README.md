## About SSAR Group

**SSAR Group** is a software and technology company focused on building reliable tools for developers, game studios, and online communities.

We develop products across **game development**, **software engineering**, **developer tooling**, and **online security**, with a focus on performance, reliability, and ease of use.

Our goal is simple: **build technology that developers can rely on.**

## Products

### Vecteur Anti-Cheat

**AI-powered security for online games.**

Vecteur is a next-generation anti-cheat system designed to detect and prevent cheating with advanced detection capabilities while keeping performance impact to a minimum.

[Explore Vecteur →](https://dev.ssar-group.com/gamedev/ac-vecteur)

### ASL Framework

**A utility framework for modern software development.**

ASL provides developers with a collection of utilities, libraries, and tools designed to simplify application development and accelerate common workflows.

[Explore ASL →](https://dev.ssar-group.com/asl)

### WalletPro Studio

**Native Apple Wallet pass creation for macOS.**

WalletPro Studio is a native macOS application for designing, editing, previewing, signing, and generating Apple Wallet passes.

[Explore WalletPro Studio →](https://dev.ssar-group.com/wallet-pro-studio)

### OPM

**Modern project scaffolding and dependency management.**

OPM is a cross-ecosystem CLI designed to simplify project creation, dependency management, and development workflows through reusable templates.

[View OPM on GitHub →](https://github.com/ssar-group/opm)

## Open Source

Open source is an important part of how we build and share technology.

SSAR Group develops, maintains, and contributes to open source projects across multiple domains. Public repositories use standardized **status labels** to communicate their current development and maintenance state.
