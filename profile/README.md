## About SSAR Group

**SSAR Group** is an independent software and technology company focused on designing, engineering, and maintaining modern digital solutions.

We build software, developer tools, frameworks, and technologies that empower developers, game studios, and digital communities. Our work spans multiple areas of software engineering, including **developer tooling, game development, application security, automation, and native software solutions**.

From low-level development tools to complete software environments, we aim to deliver products that combine performance, reliability, usability, and thoughtful engineering.

Our mission is simple:

<p align="center">
  <strong>Building technology that moves software development forward.</strong>
</p>

## Products & Technologies

Our ecosystem consists of several products and technologies designed to address different challenges across software development, game development, and digital technology.

### Studio Suite

**A collection of integrated software applications and development environments.**

Studio Suite is SSAR Group's ecosystem of dedicated software applications, designed to provide specialized tools and environments for developers, creators, and professionals.

Each application focuses on a specific domain while sharing the same commitment to usability, performance, reliability, and thoughtful engineering.

**Applications within Studio Suite:**

- **OpenStudio** - A modern development environment designed to streamline software engineering workflows.
- **RustStudio** - A dedicated integrated development environment for Rust development.
- **NexusStudio** - A specialized environment for scientific software and engineering tools.
- **WalletPro Studio** - A native macOS application for designing, editing, previewing, signing, and generating Apple Wallet passes.

[Explore Studio Suite →](https://dev.ssar-group.com)

### Vecteur Anti-Cheat

**Advanced security and cheat detection for online games.**

Vecteur is an anti-cheat solution designed to detect, analyze, and prevent cheating in online gaming environments, with a focus on advanced detection mechanisms and minimal performance overhead.

[Explore Vecteur →](https://dev.ssar-group.com/gamedev/ac-vecteur)

### ASL Framework

**A utility framework for modern software development.**

ASL provides developers with reusable utilities, libraries, and development tools designed to simplify application development and accelerate common engineering workflows.

[Explore ASL →](https://dev.ssar-group.com/asl)

### OpenScript Package Manager (OPM)

**Modern project scaffolding and dependency management.**

OPM is a cross-ecosystem command-line package manager designed to simplify project creation, dependency management, and development workflows through reusable templates and integrated tooling.

[View OPM on GitHub →](https://github.com/ssar-group/opm)

## Open Source

Open source is an important part of our engineering philosophy.

We believe in building software that can be explored, improved, and shared with the developer community. SSAR Group maintains and contributes to public repositories across multiple technological domains.

Our repositories follow a standardized status-label system to communicate their development lifecycle, maintenance state, and stability.

### Repository Status

| Label | Status | Description |
| :--- | :--- | :--- |
| ![active](https://img.shields.io/badge/status-active-brightgreen.svg?colorA=303033&colorB=44cc11) | **Active** | Actively developed, maintained, and improved. |
| ![stable](https://img.shields.io/badge/status-stable-blue.svg?colorA=303033&colorB=007ec6) | **Stable** | Production-ready and maintained with bug and security fixes. |
| ![experimental](https://img.shields.io/badge/status-experimental-blueviolet.svg?colorA=303033&colorB=a08a2c) | **Experimental** | Under active exploration, early development, or subject to breaking changes. |

Security and responsible disclosure are essential to our development process.

If you discover a vulnerability affecting one of our products, services, or repositories, please report it privately so our team can investigate and address the issue responsibly.

**Security reports:** [security@ssar-group.com](mailto:security@ssar-group.com)

Please avoid disclosing vulnerabilities through public GitHub issues or discussions.
